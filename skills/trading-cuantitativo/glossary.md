# Glossary — Machine Learning for Trading, 3rd Ed. (Jansen)

Alphabetical order. Format: **Term** — definition (Ch N).

**ACI** — Adaptive Conformal Inference: α_{t+1} = α_t + γ(α − err_t); controls long-run coverage (Ch 11)
**ADF / KPSS** — stationarity tests with opposite nulls (unit root vs stationarity) (Ch 9)
**ADWIN / DDM** — online drift detectors on prediction errors (Ch 26)
**Adverse selection / Inventory risk** — liquidity-provider frictions that set spreads (Ch 3)
**Adversarial SDF** — pricing kernel with no-arbitrage and adversarial test portfolios (minimax) (Ch 14)
**Agent loop** — Perception/Reasoning, Planning, Action, Observation, with tools and memory (Ch 24)
**Alpha / Edge / Capacity** — performance vs benchmark / repeatable net advantage / capital before degradation (Ch 6)
**Alpha decay** — the anomaly gets arbitraged away after publication or through crowding; ~50-58% (McLean-Pontiff) (Ch 4, Ch 6, Ch 26)
**Alpha factory** — repeatable process that generates, evaluates, deploys and monitors strategies (Ch 1, Ch 27)
**Alpha-to-go** — alpha discounted by the cost of building and unwinding the position (Ch 18)
**ALFRED / vintage** — archival FRED with real-time windows; "what was known when" (Ch 4)
**Allocator term sheet** — fixes objective, inputs, constraints, rebalancing, costs and evaluation before optimizing (Ch 17)
**Almgren-Chriss** — min E[cost] + λ·Var[cost]; front-loaded trajectory; λ = urgency (Ch 18)
**Assumption stacking** — mildly favorable assumptions that together manufacture performance (Ch 1)
**ASOF join** — aligns unsynchronized events (trade with prevailing quote); sorted inputs (Ch 2, Ch 3)
**ATE / ATT / CATE** — average causal effect / on the treated / conditional on covariates (Ch 15)
**Auditable masks** — eligibility mask stored as a definition, with effective N per fold/group (Ch 7)
**AUC 0.55-0.60** — significant predictive power in finance; >0.65 OOS is suspicious (Ch 11)
**Backdoor criterion** — W blocks non-causal paths into T and contains no descendants of T (Ch 15)
**Bagging vs boosting** — averaging independent trees (variance) vs sequential corrections (bias) (Ch 12)
**Bias-variance** — MSE = Bias² + Var + σ²; unbiased OLS does not minimize MSE (Ch 11)
**Bid-ask bounce** — negative first-order autocorrelation in tick returns (Ch 3)
**Bipower variation / Lee-Mykland** — jump-robust variance / jump test with local vol (Ch 3)
**Bitemporal storage / as-of query** — valid time and `available_at`; latest period eligible at t and latest version with availability ≤ t (Ch 2, Ch 4)
**Block-permutation refutation** — shuffles the treatment in blocks (7 days) respecting autocorrelation (Ch 15)
**BM25** — TF-IDF-style lexical ranking with length and saturation; strong on tickers and codes (Ch 10, Ch 22)
**BBP / Marchenko-Pastur** — threshold 1+√γ (γ = N/T) to recover a factor; noise benchmark for eigenvalues (Ch 14)
**Brier / log score / ECE / sharpness** — probabilistic quality metrics (Ch 24)
**BSTS** — Bayesian counterfactual from pre-event controls; impact = observed − projected (Ch 15)
**CAE (conditional autoencoder)** — nonlinear generalization of IPCA: beta network + factor side, reconstruction loss (Ch 14)
**Cantelli bound** — P(losing period) ≤ 1/(1+SR²) with no distributional assumptions (Ch 19)
**Capacity** — AUM at which net Sharpe falls below the threshold (typ. 0.5) (Ch 18)
**CatBoost** — GBM with ordered target statistics and symmetric trees; better GPU and inference, leakage-free categoricals (Ch 12)
**Chunk size** — default 400-600 tokens, overlap 50-100; evaluate 256/512/768/1024 (Ch 22)
**Circuit breakers (4 levels)** — per-trade, strategy, portfolio, system; CLOSED/OPEN/HALF_OPEN in software (Ch 26)
**client_order_id** — idempotency key; prevents duplicates after a timeout or crash (Ch 25)
**Collider / Mediator / Confounder** — common effect / intermediate channel / common cause in a DAG (Ch 7, Ch 15)
**Concept drift** — the feature-target relationship changes (sudden/gradual/incremental/recurring) (Ch 1, Ch 26)
**Confidence tiers** — ~95% auto-accept, 85-95% review, <85% escalate (Ch 4)
**Conformal position sizing** — weights ∝ 1/conformal interval width (Ch 17)
**Contamination** — the LLM memorizes outcomes; pre-cutoff evaluation is not identifiable (Ch 24)
**Context engineering** — exposing at each step only the relevant state, tools and sources (Ch 24)
**Continuous futures series** — perpetual ticker with roll rules and ratio or difference adjustment (Ch 2)
**Corporate actions** — splits, dividends, spinoffs, mergers; a 7:1 split looks like −86% (Ch 2)
**Cost capacity / break-even cost** — cost per dollar traded that exhausts the gross excess: c* = excess/turnover (Ch 16)
**CPCV** — Combinatorial Purged CV; C(n,k) train/test combinations (Ch 6)
**CQR** — conformalized quantile regression; adaptive width with conformal correction (Ch 11)
**Data drift** — change in the feature distribution; an investigation flag, not a diagnosis (Ch 1)
**Data integrity gates** — Pandera/Great Expectations; fail-closed on critical feeds (Ch 26)
**Decision cadence / Holding period / Forecast horizon / Lookback** — four distinct time scales (Ch 6)
**Deep hedging** — hedging as direct CVaR optimization with costs; produces no-transaction bands (Ch 19, Ch 21)
**DML (Double ML)** — residualize T and Y against X with ML (cross-fitting) and regress the residuals; analogue of Frisch-Waugh-Lovell (Ch 15)
**DML causal screen** — DML effect, HAC p, refutation p, bias %; passes with p<0.05 and refutation p>0.05 (Ch 20)
**DQN** — Q-network with experience replay and target networks; discrete actions only (Ch 21)
**Drawdown asymmetry** — −30% requires +43%; −50% requires +100% (Ch 19)
**Dollar bars** — bars by traded value; robust ML default regardless of price level (Ch 3)
**Encoder-only / decoder-only** — bidirectional (embeddings, classification) vs causal (generation) (Ch 10)
**Entity resolution** — mapping records from different sources to the same issuer/instrument (Ch 4)
**Equal weight (1/N)** — null model; no estimation, hard to beat OOS (Ch 17)
**Evidence boundary** — separation of exploration (logged trials) vs confirmation (sealed holdout, frozen spec) (Ch 1)
**Event / Knowledge / As-of time / Reference period** — occurrence / publication / reconstruction / period it refers to (Ch 2)
**Exchangeability** — assumption behind the conformal guarantee; markets violate it (Ch 11)
**Extract-to-schema** — structured Entity/Event/Attribute/Uncertainty output with abstention (Ch 10)
**Factor mirage** — measurement that looks precise but is causally wrong due to misspecification (Ch 1)
**Factor zoo** — hundreds of factors; core: market, value, momentum, profitability, investment (Ch 14)
**Factor-mimicking portfolio** — minimum-residual-risk portfolio that isolates a factor (Ch 17)
**Technical vs statistical failure** — pipeline bug vs correct model that decays (Ch 26)
**Falsification mindset** — look for what would refute the result instead of confirming it (Ch 16)
**Feature specification template** — name, family, role, driver, inputs, lookback, frame, representation, failure modes (Ch 8)
**Feature triage ledger (FDR)** — Benjamini-Hochberg 5% + sign stability + monotonicity; PROCEED/REVISE/STOP (Ch 20)
**Fidelity-Utility-Privacy** — three criteria for evaluating synthetic data; they compete with each other (Ch 5)
**Finance transfer gap** — pretraining (seasonality, trend) vs returns (heavy tails, low SNR) (Ch 13)
**FLAM** — IR ≈ IC × √BR; doubling IC is equivalent to quadrupling breadth (Ch 17)
**Fractional differencing (d ∈ (0,1))** — real-valued differencing that preserves memory while achieving stationarity (Ch 9)
**Fragility audit** — edge under 2× costs, delay, size caps and intra-bar shift (Ch 1)
**FWER vs FDR** — Holm-Bonferroni (≥1 false positive) vs Benjamini-Hochberg (expected fraction of false positives) (Ch 7)
**Garman-Klass / Parkinson / Yang-Zhang** — range-based estimators, efficiency ~7x / ~5x / ~8-14x vs close-to-close (Ch 8)
**GARCH half-life** — ln(0.5)/ln(α+β); SPY α≈0.17, β≈0.80 → ~23 days (Ch 9)
**Gating / Scaling / Conditional variant** — signal × state interaction templates (Ch 8)
**GMM regime map** — Gaussian clustering of factor returns; a risk lens (Ch 1)
**GNN (GCN/GAT/GraphSAGE)** — message passing; production-ready in fraud, experimental in alpha (Ch 23)
**Gradient Boosting Machine (GBM)** — additive ensemble of shallow trees fit on pseudo-residuals, scaled by the learning rate (Ch 12)
**Graph RAG explicit vs community-summary** — auditable deterministic traversal vs thematic synthesis (Ch 23)
**HAC (Newey-West)** — standard errors robust to serial dependence (Ch 7)
**HAC IC interval** — daily IC corrected for autocorrelation; one that excludes zero is the signal bar (Ch 12)
**Hallucination** — plausible but false output; an intrinsic property of the model (Ch 22)
**HAR** — regression of RV on daily, weekly and monthly RV; SPY β_w≈0.43, RMSE 0.061 vs 0.111 GARCH (Ch 9)
**HRP** — hierarchical clustering + recursive bisection inverse to cluster variance; no matrix inversion (Ch 17)
**Huber / MAE / MSE** — losses for robust hybrid, median and mean (Ch 11)
**Hurst exponent** — roughness; index log-vol H≈0.12-0.23 (rough); 252-day window (Ch 9)
**Identifier integrity** — joins on permanent IDs with effective dates; ticker reuse manufactures correlation (Ch 2)
**ICIR / sign consistency / positive-fold share** — mean IC/std across folds; fraction of folds with the median sign (Ch 7, Ch 20)
**Implementation Shortfall (IS)** — (P_exec − P_decision)/P_decision for buys; standard TCA metric (Ch 18)
**Implied-realized spread** — IV minus future RV; proxy for the variance risk premium (Ch 8)
**Incumbent vs candidate** — model in production vs replacement in shadow (Ch 26)
**Index-Retrieve-Generate** — RAG pipeline: index offline, top-k by cosine, generate only from context (Ch 22)
**Information-driven bars** — tick/volume imbalance and run bars (Ch 3)
**Inverse volatility** — w ∝ 1/σ; equalizes standalone vol, not risk contribution (Ch 17)
**IPCA** — instrumented PCA: betas = Γ'z with lagged characteristics; ALS (Ch 14)
**iTransformer** — variate-as-token: attention operates across variables (Ch 13)
**Kelly criterion** — f* = edge/odds; continuous μ/σ²; multi-asset Σ⁻¹μ; use fractional 1/2-1/4 (Ch 17)
**Kill switch** — precommitted rule that halts the strategy; 4 levels: pause signals, cancel, flatten, shutdown (Ch 18, Ch 25)
**Knowledge graph (KG)** — typed nodes and edges with IDs, timestamps and provenance (Ch 23)
**Kyle's lambda** — price sensitivity to net order flow; input to cost models (Ch 3, Ch 8)
**K-S test** — maximum distance between CDFs; no binning (Ch 26)
**L1 / L2 / L3** — top-of-book / market-by-price / market-by-order (deterministic replay) (Ch 3)
**Label / Standardization / Threshold leakage** — three forms of lookahead in the pipeline (Ch 6)
**Label buffer (purging) / Feature buffer (embargo)** — gaps in trading days against overlap; embargo ~1% (Ch 6)
**Label engineering** — 1/99 winsorization, horizon, regression vs classification; pays off more than architecture (Ch 20)
**LambdaMART (lambdarank)** — ranking GBM that optimizes NDCG with groups by date (Ch 12)
**Leakage by construction** — features, labels or prompts that incorporate the future, even via the LLM's training (Ch 1)
**Ledoit-Wolf shrinkage** — Σ̂ = (1−α)S + αF; shrinks extreme eigenvalues before PCA/MVO (Ch 14, Ch 17)
**Lee-Ready** — aggressor classification via quote test + tick test; ~94.7% accuracy (Ch 3)
**LEI / CIK / FIGI / CUSIP-ISIN-SEDOL** — IDs for entity, SEC filer, instrument and security (Ch 4)
**Linear slippage** — cost ∝ α·(Q/V); 0.5%-2% ADV; 2-3x in high vol (Ch 18)
**LightGBM** — GBM with histograms, leaf-wise growth, GOSS and EFB; the fastest on CPU (Ch 12)
**LOB reconstruction** — state machine with an order registry and a per-price-level view, with invariants (Ch 3)
**Logistic log-odds** — β linear in log-odds; regularization prevents perfect separation (Ch 11)
**Lo (2002) autocorrelation adjustment** — SR(q) = q·SR(1)/√(q+2Σ(q−k)ρ_k) (Ch 16)
**LoRA** — low-rank fine-tuning; cuts memory 60-80% (Ch 10)
**Loughran-McDonald** — 6-list financial lexicon; Harvard GI misclassifies ~3/4 of "negatives" (Ch 10)
**LSTM / GRU** — gated RNNs; sequential O(L) compute; GRU has ~1/4 fewer parameters (Ch 13)
**LTSF-Linear (Linear, D-Linear, N-Linear)** — single-layer baselines; D decomposes trend/seasonal, N subtracts the last value (Ch 13)
**Mamba / SSM** — selective state space, O(L); for sequences >10K steps (Ch 13)
**Market / Fundamental / Alternative data** — what the market did / economic drivers with lags / signals outside standard feeds (Ch 2)
**Markowitz curse** — unregularized MVO concentrates and is unstable OOS (Ch 17)
**Matrix pricing** — mapping illiquid bonds to similar liquid ones; model assumptions (Ch 2)
**MDP ⟨S,A,P,R,γ⟩** — sequential decision; markets are POMDPs (Ch 21)
**Meta-labeling** — secondary model predicts whether the primary signal will be profitable; probability → size (Ch 7)
**MFE/MAE** — maximum favorable/adverse excursion; calibrates barriers, stops and take-profits (Ch 7, Ch 19)
**ModernBERT** — encoder with a native 8,192-token context (Ch 10)
**Monotonic constraints** — +1/−1 feature→prediction constraint; theory-guided regularization (Ch 12)
**MS-AR** — Markov-switching autoregression with per-regime AR coefficients (Ch 9)
**ML4T Workflow** — data infrastructure (Ch 2-5) + strategy research loop (Ch 6-21) + deployment/monitoring (Ch 1)
**N-BEATS / N-BEATS-I** — doubly-residual FC blocks; interpretable version with Trend and Seasonality stacks (Ch 13)
**N_eff** — effective size given overlap (SPY H=21: 248,436 → ~11,830); with weights: (Σw)²/Σw² (Ch 7, Ch 11)
**NBBO** — consolidated best bid/offer in the U.S. (Ch 2)
**NCO** — optimizes within clusters and then across them; accepts views (Ch 17)
**NDCG** — ranking metric that rewards getting the top right (Ch 12)
**Neyman extremization** — d = √(n/(1+(n−1)ρ)); p = base + d(p_mean − base) (Ch 24)
**Next-open-to-open / Close-to-close** — signal at close t, entry at open t+1 / close-to-close return; they differ by 50-100 bps per trade (Ch 7)
**No-transaction band** — region where you do not rebalance because the cost exceeds the benefit (Ch 21)
**NOTEARS** — cross-sectional DAG with differentiable acyclicity tr(e^{W∘W})−d=0 (Ch 15)
**NSGAIISampler** — multi-objective optimization (Pareto frontier, e.g. IC vs turnover) (Ch 12)
**Observability** — every input observable at decision time, including reporting lags (Ch 7)
**OFI** — order flow imbalance: normalized cumulative signed flow (Ch 8)
**Online detection** — detecting change in real time using only decision-time information (Ch 1)
**OPE** — offline policy evaluation via importance weighting or doubly robust (Ch 21)
**Optuna (TPE) / nested CV** — sequential HPO; nested corrects validation overfitting (single-loop +0.028 vs nested −0.032) (Ch 11, Ch 12)
**Order state machine** — 10 states, 19 transitions; PENDING_CANCEL for concurrent cancel/fill (Ch 25)
**Ordered target statistics** — target encoding using only prior samples in a permutation (Ch 12)
**Participation rate** — Q/ADV; determines the impact model (Ch 18)
**PatchTST / Patching** — non-overlapping patches as tokens, O((L/P)²), channel-independence, RevIN (Ch 13)
**PCA / eigenportfolio** — covariance eigenvectors as orthogonal portfolios; PC1 ~ market (corr 0.99) (Ch 14)
**PCMCI** — causal discovery in time series: PC phase + MCI (Ch 15)
**Phased deployment** — shadow, canary, full scale (Ch 1)
**Placebo / negative control** — fake treatment, date or outcome that should give ~0 (Ch 15)
**Platt scaling / isotonic** — parametric / nonparametric probability calibration; Platt on a disjoint window (Ch 11, Ch 24)
**Point-in-time (PIT)** — each value reflects what was knowable at decision time under the definitions then in force (Ch 2)
**Polysemy** — a word with several senses that static embeddings conflate (Ch 10)
**Pooled Sharpe / SoftMin loss** — Sharpe over concatenated returns / penalizes the worst sub-windows (DeePM) (Ch 17)
**PPO** — on-policy actor-critic with clipped surrogate; stable default, less sample-efficient (Ch 21)
**PR AUC** — more informative than ROC AUC when the positive class is rare (Ch 7)
**Prediction-first vs Mechanism-first** — high-capacity forecasting vs economic rationale that bounds the search (Ch 1)
**Prediction-quality / portfolio-translation drift / regime change** — three mechanisms of validation→holdout decline (Ch 20)
**Pre-registration** — fixing thesis, signal and criteria before the backtest (Ch 6)
**Pre-train → adapt → fine-tune** — general, domain (continued MLM), task (supervised head) (Ch 10)
**Pipeline verification** — per-stage parity: data, features, predictions, signals, orders (Ch 25)
**PSI** — Σ(A_i−E_i)ln(A_i/E_i); <0.10 stable, 0.10-0.25 moderate, >0.25 retrain (Ch 19, Ch 26)
**PSR / DSR** — Probabilistic / Deflated Sharpe: adjust for skewness, kurtosis, T and effective trials (Ch 16)
**QLIKE / MSE of variance** — losses robust to the vol proxy; QLIKE penalizes under-prediction (Ch 19)
**Rademacher Anti-Serum** — simultaneous lower bounds for correlated strategies (Ch 16)
**RAG** — the LLM synthesizes only over evidence retrieved from a curated external base (Ch 22)
**RAGAs / RAGChecker** — context precision/recall, faithfulness, relevance, abstention / unsupported claim rate (Ch 22)
**Rank IC** — cross-sectional Spearman of feature vs label; triage default (Ch 7)
**ReAct** — Thought-Action-Observation loop; RAG becomes a tool (Ch 22, Ch 24)
**Realization ratio** — live Sharpe / backtest Sharpe (Ch 26)
**Reconciliation** — positions, orders and cash, daily and at startup; halt on discrepancy (Ch 25)
**Recursive / direct multi-horizon / direct horizon-label** — three forecast targets; the third dominates in cross-sectional ranking (Ch 13)
**Regime** — persistent state with vol/correlations stable within and different across states (Ch 1)
**Regime-conditional VaR/CVaR** — by vol regime; SPY CVaR 95% 4.33% vs 1.63% (~2.7x) (Ch 19)
**Regime-sliced performance** — metrics by 4 vol × trend states (Risk-on, Caution, Crisis, Recovery) PIT (Ch 16)
**Research ledger** — record of trials used to count and characterize the search (Ch 1)
**Reservation price (Avellaneda-Stoikov)** — indifference price shifted from the mid by inventory (Ch 21)
**Revision / amendment leakage** — revisions that alter history; snapshot at first availability (Ch 10)
**Rashomon Effect** — equally good models with different explanations; validate across families (Ch 12)
**Ridge / LASSO / Elastic Net** — L2 (diffuse signal), L1 (sparse), mix with grouping; l1_ratio 1.0 = LASSO (Ch 11)
**Risk contribution** — each position's contribution to total vol; equal capital ≠ equal risk (Ch 17)
**Risk parity / ERC** — equal risk contribution; between min-var and equal weight; requires leverage (Ch 17)
**RP-PCA** — PCA with a pricing-error penalty (κ=1+γ); rescues low-variance, high-premium factors (Ch 14)
**RRF** — Reciprocal Rank Fusion: sum of 1/(k+rank), k=60 (Ch 22)
**SAC / TD3 / DDPG** — off-policy actor-critic for continuous actions; SAC adds entropy (Ch 21)
**SAE (supervised autoencoder)** — bottleneck with a supervised head; predictive benchmark (Ch 14)
**Sealed holdout / Nested walk-forward** — final block used once / outer test and inner selection (Ch 6)
**SafeBroker** — applies caps, a persisted daily-loss kill switch and staleness checks on every order (Ch 25)
**Searched set** — all candidates evaluated under the same rules; its size accompanies any p-value (Ch 7)
**Selection inflation** — best in-sample grows with no-edge trials; 10 trials → expected max Sharpe 1.57 (Ch 5)
**Self-attention (Q,K,V)** — softmax(QKᵀ/√d_k)V; quadratic cost in length (Ch 10)
**Sequential bootstrap** — resampling that favors observations with less overlap (Ch 7)
**SHAP monitoring / stability chart** — mean |SHAP| per fold/window; early warning (change >50%) (Ch 11, Ch 12, Ch 26)
**Signal vs State variable** — predicts mean/direction vs conditions when and how much to trade (Ch 8)
**Split-aware preprocessing / Train-only fitting** — refit fitted transforms in each fold; stateless ones do not need it (Ch 7)
**Split-conformal** — q̂ = s_(⌈(n+1)(1−α)⌉) over absolute calibration residuals; fixed width (Ch 11, Ch 13)
**SR 11-7** — model risk guidance: effective challenge, monitoring, documentation (Ch 26)
**Spread / Depth / Resiliency** — cost of immediacy / quantity available / replenishment speed (Ch 3)
**Square-root impact** — C = η·σ·√(Q/V); η 0.1-0.5; >2% ADV; concave (Ch 18)
**Stationary bootstrap** — blocks of geometric length; a better default than fixed blocks (Ch 5)
**Strategy map** — families (feasibility) and sources of edge (durability) (Ch 6)
**Structural break** — abrupt change in the data-generating process; the "when" (Ch 1)
**Structure-aware parsing** — LlamaParse/Docling/Marker; preserve sections and tables (Ch 22)
**Stylized facts** — heavy tails, volatility clustering, leverage effect, weak autocorrelation (Ch 5)
**Survivorship bias** — universe filtered with future information; sign depends on the delisting cause (Ch 2)
**Synthetic / simulated / generated scenarios** — samples from a fitted model / parametric Monte Carlo / regime-conditioned (Ch 5)
**TAQ** — Trades and Quotes; sufficient for most medium-horizon strategies (Ch 3)
**TCA** — measurement and decomposition of realized costs to recalibrate ex ante models (Ch 18)
**Temporal credit assignment** — attributing an outcome to the sequence of actions; V(s) solves it (Ch 21)
**Temporary vs permanent impact** — liquidity pressure that reverts vs informational footprint that persists (Ch 18)
**TF-IDF** — weighting by rarity (Ch 10)
**Threshold spiral** — positive feedback in imbalance bars with a high EWMA (17.5x vs 0.98x with α=0.001) (Ch 3)
**Three-stage adapter** — estimate factors, forecast the premium, map μ = β'λ_hat (Ch 14)
**Three-step filter** — horizon alignment, driver hypothesis, role separation (Ch 8)
**Timing placebo** — shift the feature by Δ bars and watch the IC decay (Ch 7)
**TimeGAN** — GAN with embedding, supervisor and phases for multivariate sequences (Ch 5)
**Top cluster / Ensembling top-3** — configurations indistinguishable by bootstrap / cross-sectional z-score and average (Ch 20)
**Trading setup** — versioned invariants for universe, schedule, mapping, constraints and costs (`setup.yaml`) (Ch 6)
**Training-serving skew / Feast** — features that differ between training and inference; offline vs online store (Ch 26)
**Trial accounting / taxonomy** — every adaptive choice is a trial; Strategy > Trial family > Trial > Run (Ch 6, Ch 16)
**Tree of Thoughts (ToT)** — parallel exploration of branches before choosing (Ch 24)
**TreeSHAP** — exact Shapley values in O(TLD²) for trees; main effects and interactions (Ch 12)
**Triple-barrier label** — +1/−1/0 depending on which barrier (upper, lower, vertical) is touched first (Ch 7)
**Trend scanning** — per observation, the horizon (5-60 bars) with the highest trend t-stat (Ch 7)
**TSFM (Chronos, TimesFM, Moirai)** — time-series foundation models; poor zero-shot on returns (Ch 13)
**TSTR / TRTR** — train synthetic test real / train real test real; ratio ~1 = utility preserved (Ch 5)
**Two gates** — |t_HAC|>1.96 and p_ref<0.05; they rarely agree (Ch 15)
**Uniqueness / concurrency** — w_t = mean of 1/c(u); c(u) = labels alive at bar u (Ch 7)
**VaR / CVaR (Expected Shortfall)** — loss quantile / expected loss beyond it; CVaR is subadditive (Ch 19)
**VAR-LiNGAM** — lagged + contemporaneous structure, non-Gaussian errors, acyclic (Ch 15)
**Vectorized vs event-driven** — path via arrays vs stateful simulation (cash, margin, orders) (Ch 16)
**Volatility targeting** — scales exposure by σ_target/σ_base (15%→10% = ×0.67) (Ch 17)
**Volatility-scaled threshold** — τ_t = k·σ̂ past-only; stabilizes the base rate across regimes (Ch 7)
**Walk-forward CV** — fit on the past, predict the future, roll forward (Ch 6)
**White's Reality Check / SPA** — joint bootstrap: does the best candidate exceed what the search itself produces? (Ch 16)
**XGBoost** — regularized GBM (γ, λ), sparsity-aware, 2nd order, CUDA GPU; best ecosystem (Ch 12)
